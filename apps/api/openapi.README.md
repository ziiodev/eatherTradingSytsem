# `apps/api/openapi.json`

This file is the **committed snapshot** of the FastAPI OpenAPI schema for the
Aether HTTP API. It is the canonical input to the TypeScript type generation
in `packages/shared-types/`.

## How it is produced

The file is regenerated by running:

```bash
cd apps/api && uv run python scripts/dump_openapi.py
```

That script imports the FastAPI app (`aether_api.main.app`), calls
`app.openapi()`, and writes the JSON to `apps/api/openapi.json` with stable
key ordering and a trailing newline so the diff stays minimal.

The repo root Makefile chains both the schema dump and the TS codegen into a
single target:

```bash
make gen.types
```

That target runs:

1. `apps/api/scripts/dump_openapi.py` → updates this file.
2. `pnpm --filter @aether/shared-types gen` → updates
   `packages/shared-types/src/api.ts`.

## Why it is committed

Committing the snapshot lets the frontend type-check without booting the
backend, and surfaces API contract changes as a visible diff during code
review. The current committed content is a minimal valid OpenAPI 3.1 doc
that exists only so the toolchain has a real file to point at while the
backend boot path is being stabilized — the real schema will populate it as
soon as the first contributor runs `make gen.types` with the API
dependencies installed.

## CI drift gate

CI regenerates this file on every PR and runs `git diff --exit-code`. If the
checked-out source produces a different schema than what is committed, the
job fails with a message like:

```
apps/api/openapi.json is out of sync. Run `make gen.types` and commit.
```

That gate is the single mechanism that keeps the frontend types and the
backend code from drifting apart.

## When to regenerate

Regenerate (and commit the change) whenever you:

- Add, remove, or rename a FastAPI route.
- Change a Pydantic request/response model field, type, alias, or example.
- Change `aether_api.__version__` (the version surfaces in `info.version`).

Always commit the regenerated `openapi.json` together with
`packages/shared-types/src/api.ts` and the backend change that caused them.
