# @aether/shared-types

Canonical TypeScript surface for the Aether HTTP API.

This package is a **source-only**, **private** workspace package. Its single
job is to expose the FastAPI OpenAPI schema as TypeScript types so the
frontend (and any future TS consumer) can call the API in a type-safe way.

## Layout

```
packages/shared-types/
  src/
    api.ts      ← AUTO-GENERATED by openapi-typescript. Committed.
    index.ts    ← Re-exports `paths`, `components`, `operations`, `Schemas`.
  package.json
  tsconfig.json
```

`src/api.ts` is generated from `apps/api/openapi.json`, which is itself a
snapshot of the live FastAPI schema. We commit both files so:

1. The frontend type-checks without needing the backend to be running.
2. PRs that change the API contract have a visible diff in `api.ts`.
3. CI can detect drift between code and committed schema (see below).

## Regeneration flow

There are two ways to regenerate:

### 1. From the committed snapshot (offline-friendly)

```bash
pnpm --filter @aether/shared-types gen
```

This reads `apps/api/openapi.json` and writes `src/api.ts`. Use this when you
just pulled changes from `main` and want to regenerate locally without
booting the backend.

### 2. From a running backend (the source of truth)

```bash
# Terminal 1: boot the API
cd apps/api && uv run aether-api

# Terminal 2: regenerate against the live schema
pnpm --filter @aether/shared-types gen:from-running
```

Use this when you have **just changed the FastAPI code** (added a route,
changed a Pydantic model, etc.) and want the new schema reflected in TS.

### End-to-end: regenerate everything

The Makefile target chains the snapshot dump and the TS codegen:

```bash
make gen.types
```

That target:

1. Runs `apps/api/scripts/dump_openapi.py` → updates `apps/api/openapi.json`.
2. Runs `pnpm --filter @aether/shared-types gen` → updates `src/api.ts`.

## When to run regeneration

Run `make gen.types` whenever you:

- Add, remove, or rename a FastAPI route.
- Change a Pydantic request/response model field, type, or alias.
- Change the API version in `aether_api.__version__`.

Commit both regenerated files (`apps/api/openapi.json` and
`packages/shared-types/src/api.ts`) in the **same** commit as the backend
change. This keeps the contract atomic.

## CI drift gate

The frontend CI job regenerates both files from the checked-out source and
then runs `git diff --exit-code`. If the diff is non-empty, the job fails
with a message like:

```
shared-types is out of sync with apps/api. Run `make gen.types` and commit.
```

This is the single source of truth that prevents the frontend from drifting
away from the backend contract.

## Consumption

Apps depend on this package via the pnpm workspace protocol:

```jsonc
// apps/web/package.json
{
  "dependencies": {
    "@aether/shared-types": "workspace:*"
  }
}
```

And import either the umbrella module or the generated submodule directly:

```typescript
import type { paths, components, Schemas } from "@aether/shared-types";
// or, for tree-shaking sensitive code:
import type { paths } from "@aether/shared-types/api";
```

See `apps/web/src/lib/api.ts` for the `ApiResponse<P, M>` helper that turns
a `(path, method)` pair into the concrete success-response body type.
